## Documented exceptions to the rule
1. CPU requests are not set from the median: the api median (6m) is idle time and the HPA scales on 70 percent of the api CPU request, so 100m stays (K3); the indexer median (2m) is time spent waiting for Ollama, while OCR uses a full core.
2. Floors: CPU limit at least 250m (startup and request bursts), memory limit at least 64Mi.
3. This replaces the K10 values (api 256Mi, chroma 512Mi, indexer 1Gi, eval 256Mi); see docs/architecture/deviations.md DEV-018.
