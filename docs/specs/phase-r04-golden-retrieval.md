## 1. Objective

A golden set of 34 labelled questions and the first two measurement levels of Part B: the embedding model on its own (module) and retrieval through the live retriever (component), plus a seeded typo noise test. Without it R5 to R7 have nothing to measure or gate on.

## 2. Context

- Requirements: R3-B-1 to R3-B-5.

## 3. Scope

**In scope**: `golden.jsonl` (loader, validator, `--check`), metric functions (recall@3/5, MRR, nDCG@5, percentile, seeded typos), module level (30 pairs, per-chunk time, determinism), component level (clean and noisy, per group), `/api/retrieve`.

**Out of scope**: answer level, stochasticity, one command (R5); trace (R6); gate (R7); the baseline numbers and the human work of D-126 (pending, listed as ACs below).

## 4. Interfaces and contracts

- `golden.load(path, subset="all"|"A"|"B") -> list[dict]`; `golden.counts(rows)`; `golden.problems(rows) -> list[str]`; CLI `python -m eval.suite.golden --check [--golden F] [--out F]` exits 1 when `--check` and any problem. `MINIMUMS` = 25 questions, 15 answerable, 5 unanswerable, 5 hard, 8 human, 8 synthetic reviewed.
- Row: `id, question, kind (answerable|unanswerable), hard, origin (human|synthetic), reviewed, relevant [{source, section, page}], expect, batch (A|B), tags, must_abstain`.
- `metrics.recall_at_k/reciprocal_rank/ndcg_at_k(relevant, retrieved, k) -> float|None` (None when `relevant` is empty); matching is `source ==` and A02 `section_matches`.
- `metrics.add_typos(text, seed, rate=1/8)`: words of 4 or more letters, one edit (swap, drop, duplicate, replace).
- `component_level.run(api, rows, seed) -> {clean, noisy, noise_delta, retrieval_ms_*}`; `module_level.run(pairs_path, chunk_texts, embedder)`.
- HTTP: `POST /api/retrieve {question, k}` returns `retrieved[{rank, chunk_id, source, section, page, score, text}], scope, index_id, embed_model, ms_retrieve`; no model call. Not a frozen contract (DEV-017).
- Config: `OLLAMA_URL`, `EMBED_MODEL` for the module level.

## 5. Behaviour and design details

- nDCG: binary gain, a relevant pair gains once at its first match; IDCG puts `min(|R|, k)` gains on top.
- Unanswerable questions have empty `relevant` and are excluded from retrieval metrics.
- Noise seed per question is `seed + sum(ord(c) for c in id)`: stable across runs and Python hash seeds.
- Module level embeds with the `search_query:` prefix for pairs and `search_document:` for chunks; reports paraphrase mean, unrelated mean, gap, median and p95 ms per chunk (up to 100 chunks), bytes per embedding, determinism max abs difference over two identical calls.
- Origin labels: 18 `human` (A02 questions), 16 `synthetic` (`g*` ids, generated by `build_golden_jsonl.py`, `reviewed: false` until Zain reviews, D-126).
